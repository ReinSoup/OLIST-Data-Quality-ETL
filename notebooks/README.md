# Notebooks

This folder contains the Jupyter notebooks used throughout the Olist data quality and ETL process.

## Purpose

The notebooks document the process of inspecting, assessing, cleaning, validating, and preparing the Olist datasets.

## Contents

- Raw data inspection
- Data quality assessment
- Data cleaning and transformation
- Data validation
- Cleaned data export
- SQLite database creation

Each notebook focuses on a specific stage of the project and documents the decisions made during the process.
